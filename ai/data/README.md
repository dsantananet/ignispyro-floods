# Dados — inventário e proveniência

Cada fonte tem uma entrada em `manifests/sources.json` (fonte, licença, resolução, cobertura, natureza do dado, papel, estado).
Campos `null` = por confirmar; não preencher de memória.
Natureza: `observado` | `estimado` | `modelo` | `derivado`.
Não guardar aqui dados com licença não confirmada nem restritos.
